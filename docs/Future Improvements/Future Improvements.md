# Future Improvements

The current MakerMania prototype focuses on validating the hardware platform.

Future improvements include:

## Hardware

- Larger TFT display
- Better speaker
- I2S amplifier
- Improved PCB layout
- Custom enclosure
- Better ergonomics
- USB-C charging directly on PCB

---

## Software

- Multiple built-in games
- Better UI
- Game launcher
- Save system
- OTA firmware updates
- Sound effects
- Improved animations

---

## Multiplayer

- More than three players
- Additional game modes
- Lobby system
- Score tracking

---

## Long-Term Vision

Brawl Box can evolve into a small open-source handheld gaming platform capable of running multiple retro-inspired multiplayer games.
