# Problem Statement Response Summary

## Overview

This document summarizes the early problem statements collected through the Google Form for MakerMania 2026.

The responses were reviewed to identify repeated themes, user pain points, and possible hardware/product opportunities. Some ideas were taken directly from the form responses, while some other ideas were discussed separately by the team during ideation and SCAMPER activity.

The purpose of this document is not to finalize the project problem statement, but to support early problem discovery and shortlisting.

## Initial Filtering Notes

Not every real problem becomes a good MakerMania problem statement.

Some problems were deprioritized because they were:

* too broad
* too software-heavy
* too dependent on external infrastructure
* difficult to prototype within 30 days
* unclear in terms of physical product value
* expensive or power-heavy for the current scope

---

## Stronger Directions So Far

### 1. Non-invasive automatic AC control for manual cars

This is a strong candidate because it has:

* clear user action: repeated AC adjustment
* hardware scope: temperature sensing + physical actuation
* non-invasive approach: no modification to car electronics
* prototype possibility within limited time

Main challenges:

* reliable mounting
* actuator force
* dashboard compatibility
* vibration while driving
* long-term reliability

---

### 2. Gym equipment movement quality tracker

This is being discussed because it has:

* clear target users: gym beginners / fitness users
* sensor-based hardware scope
* measurable movement data
* possible low-cost prototype using IMU-based sensing

Main challenges:

* it cannot fully track body posture with only one equipment-mounted sensor
* scope must be limited to movement quality, not full form correction
* needs validation from gym users/trainers

---

### 3. Gig worker heat and safety tracking device

This idea was selected for the SCAMPER activity and will be discussed further.

Possible direction:

* low-cost safety device for outdoor delivery/gig workers
* tracks basic safety or environmental indicators
* may include heat exposure, accident possibility, heart rate, SpO2, or weather-related risk

Current note:

* It is not finalized as the main project problem statement.
* The idea needs a more focused user pain and practical prototype scope.

## Current Understanding

The form responses helped us understand that people face many real daily-life problems, especially around travel, productivity, comfort, and safety.

However, for MakerMania, we are currently trying to focus on problems that are:

* specific
* hardware-friendly
* low-cost
* testable within 30 days
* useful for a clear target user
* practical to prototype using available tools and components
