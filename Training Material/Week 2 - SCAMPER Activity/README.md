## What is SCAMPER?

SCAMPER is an ideation framework used to improve, modify, or rethink ideas.

| Letter | Meaning             |
| ------ | ------------------- |
| S      | Substitute          |
| C      | Combine             |
| A      | Adapt               |
| M      | Modify              |
| P      | Put to another use  |
| E      | Eliminate           |
| R      | Reverse / Rearrange |

We used this framework to look at different problem directions and think about how they could be changed, simplified, improved, or made more practical.

## Selected Idea for SCAMPER Discussion

For the SCAMPER activity, we selected the idea of a:

## Low-Cost Gig Worker Heat and Safety Tracking Device

This idea focuses on delivery and gig workers who spend long hours outdoors in Indian traffic and weather conditions.

### Problem Context

Delivery and gig workers may face:

* Heat exposure
* Rain and changing weather
* Long working hours
* Traffic-related risks
* Accident possibility
* Physical fatigue
* Limited real-time safety support

### Possible Device Direction

A low-cost wearable or attachable device could track selected indicators such as:

* Heat exposure
* Heart rate
* SpO2
* Motion / fall indication
* Accident possibility
* Environmental conditions
* Basic alert output

The idea is still under discussion and has not been finalized as the main MakerMania project problem statement.

## SCAMPER Breakdown for Selected Idea

| SCAMPER Element     | Application to Gig Worker Safety Device                                                                       |
| ------------------- | ------------------------------------------------------------------------------------------------------------- |
| Substitute          | Replace expensive smartwatches or phone-based monitoring with a low-cost dedicated safety device              |
| Combine             | Combine environmental sensing, basic health monitoring, and motion/fall detection in one simple system        |
| Adapt               | Adapt wearable safety tracking concepts for Indian delivery/gig workers and outdoor working conditions        |
| Modify              | Modify the device to be lightweight, low-cost, easy to wear, and suitable for long working hours              |
| Put to another use  | Use basic health and motion sensors not just for fitness, but for outdoor worker safety                       |
| Eliminate           | Avoid unnecessary advanced features that increase cost, size, or battery usage                                |
| Reverse / Rearrange | Instead of waiting for the worker to manually ask for help, the device could detect risk and trigger an alert |

## Why This Idea Was Considered

This idea was considered because it has:

* Outdoor worker relevance

* Low-cost product possibility
* Scope for wearable/device prototyping
* Possible safety and health use case

## Key Challenges

| Challenge       | Why It Matters                                                                           |
| --------------- | ---------------------------------------------------------------------------------------- |
| Cost            | The device must stay affordable for the target user group                                |
| Battery life    | Outdoor workers may need long usage time                                                 |
| Comfort         | The device should not disturb the worker during daily tasks                              |
| Sensor accuracy | Health and safety readings should be reliable enough for prototype-level testing         |
| Problem focus   | The idea needs to be narrowed to one clear user pain instead of tracking too many things |
| Alert mechanism | The output should be simple, useful, and practical                                       |

## Learnings from the Activity

* A relatable problem does not automatically become a strong product idea.
* Some ideas sound useful but fail when the actual user pain is unclear.
* A good hardware project needs a specific user, clear pain point, and testable prototype scope.
* SCAMPER helped us expand ideas instead of jumping directly to one solution.
* The selected SCAMPER idea still needs deeper validation before being considered as the final project direction.
